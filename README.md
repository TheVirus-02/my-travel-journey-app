# ✈️ My Travel Journey App

A simple and interactive React application that showcases travel destinations and journey details through reusable components and dynamic data rendering.

## 🌍 About the Project

**My Travel Journey App** is a frontend project built to practice React fundamentals by displaying travel information in a structured and user-friendly format.

The project uses an array of travel objects to organize destination details and renders the information dynamically using React components.

🔗 **GitHub Repository:** [my-travel-journey-app](https://github.com/TheVirus-02/my-travel-journey-app)

## ✨ Features

- 🗺️ Display travel destinations and journey details.
- 📍 Show location information for each destination.
- 🌎 Organize travel data by destination, state, and google map location.
- 🔄 Dynamically render travel cards using JavaScript's `.map()` method.
- 🧩 Use reusable React components.
- 📦 Pass data between components using props.
- 🎨 Display destination information in a clean, card-based layout.

## 🛠️ Tech Stack

- **React.js** — Building reusable UI components.
- **JavaScript (ES6+)** — Managing and rendering travel data.
- **HTML5** — Structuring the application.
- **CSS3** — Styling the user interface.
- **Vite** — Development server and build tooling

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/TheVirus-02/my-travel-journey-app.git
```

### 2. Navigate to the project folder

```bash
cd my-travel-journey-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application in your browser.
